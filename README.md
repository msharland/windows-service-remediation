
# Windows Service Automation

A lightweight .NET Worker Service for running automated Windows operations, health checks, and remediation tasks.

## Purpose

This project demonstrates using C# and .NET Worker Services to automate common Windows administration and SRE tasks without requiring an interactive user session.

## Features

* Runs as a Windows Service
* Background task execution
* Scheduled automation
* Windows service health checks
* API health monitoring
* Automated remediation
* Structured logging
* Graceful shutdown and cancellation

## Example Automations

* Check whether a Windows service is running
* Restart an unhealthy service
* Monitor disk space
* Check HTTP/API endpoints
* Run scheduled maintenance tasks
* Log remediation actions

## Technology

* C#
* .NET
* Worker Service
* Microsoft.Extensions.Hosting
* Windows Services
